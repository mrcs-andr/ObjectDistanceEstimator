### Title
Fix distance estimator to report ground-plane (horizontal) distance from origin using extrinsics translation.

### Body
The DistanceEstimator currently returns 3D slant range to the ground-plane intersection point of the detection ray (bottom-center of bounding box). User expects ground-plane/horizontal distance along ground from chosen origin (world/vehicle) to that ground intersection point (option B). In extrinsics mode, code uses cameraZ only and ignores cameraX/cameraY, and returns t*||dw||. Update to compute intersection point P_world = C_world + t*d_world, where C_world=(cameraX,cameraY,cameraZ), ground is Z=0. Then return horizontal distance sqrt((P_world.x - originX)^2 + (P_world.y - originY)^2). Define origin as (0,0,0) world frame by default; optionally make origin configurable. Ensure units are metres and angles degrees as per ExtrinsicsCalibrationResult. Add tests or debug logs to validate against known geometry.

### Affected file:
app/src/main/java/com/mrcs/andr/objectdistanceestimatorapp/distance/DistanceEstimator.java lines ~127-156.

### Acceptance
With correct extrinsics, app reports ~5 m for object 5 m away on flat ground, and output is stable under pitch changes.
